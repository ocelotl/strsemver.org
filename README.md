# strsemver.org

Source for the [strsemver.org](https://strsemver.org) website: a single static
HTML document describing strsemver, a variant of Semantic Versioning. The content
is currently a placeholder while the variant is being defined.

## Hosting

The site is served by GitHub Pages from the `main` branch of this repository. The
custom apex domain `strsemver.org` is bound through the `CNAME` file at the root of
the repository. There is no build step: the files are served exactly as committed
(plain static HTML, no Jekyll, no external assets).

## View locally

Open `index.html` in a web browser. No server or build is required.
